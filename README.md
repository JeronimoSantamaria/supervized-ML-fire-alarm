## General objective
Develop a machine learning model able to detect enviromental changes that could a possible fire 
## EDA objectives
1. Determine what a normal environment is for the machine learning model
  - typical temperature
  - typical humidity
  - typical gas concentration
  - variability
  - minimum/maximum
  - distributions
  - temporal behavior
2. Determine how environments differ from each other
3. Identify which data convinations are more relevant to identify 
## Methods
### Experimentation
1. Gather normal ambient data
2. Train a preeliminar model
3. Simulate outliers in the variables by creating controlled fire scenarios and gather this data
4. Evaluate the efectivity of the model to detect outliers
5. Iterate
